# Plan 1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running, statically rendered, typed Next.js app with all tooling, i18n, theming, data layer, KPI selectors, versioned mock API, resilience primitives and CI — no designed UI yet.

**Architecture:** FSD v2.1 under `src/`, Next routing only in root `app/[locale]/`. Data is validated once with zod (`shared/api/dataset`), all KPIs come from pure selectors in `entities/performance`, every request goes through one fetch client with timeouts (`shared/api/http`). Pages are prebuilt per locale (`generateStaticParams` + `next/root-params`).

**Tech Stack:** Node 24, pnpm 10, Next.js 16.4, React 19.3, TypeScript 6.0, Tailwind 4.3 + shadcn 4.23 (Radix base), next-intl 4.14, next-themes 0.4.6, nuqs 2.10, TanStack Query 5.105, zod 4, @t3-oss/env-nextjs 0.13, eventsource-parser 4.1, Vitest 5 + Testing Library + jsdom, ESLint 10, Prettier 3.9, Steiger 0.9.

**Spec:** `docs/specs/2026-11-03-market-ops-console-design.md`. Decisions: `docs/decisions/0001–0012`. Rules: `CLAUDE.md`, `.claude/rules/*`.

**Plan series:** 1 Foundation (this) → design pass (ui-ux-pro-max + Claude Design, owner review) → 2 Assistant → 3 Dashboard → 4 Alerts → 5 E2E, deploy, README.

## Global Constraints

- Branch: work on `feature/foundation` created from `release/0.2.0`. Never commit to `release/*`, `develop`, `master`. Never push.
- `package.json` `version` = `0.2.0` = top entry of `CHANGELOG.md`.
- TypeScript `strict`, `noUncheckedIndexedAccess`; no `any`, no `as` to silence errors.
- No string literals in JSX (`i18next/no-literal-string`); all copy from `src/shared/config/i18n/messages/{en,de,ru}.json`.
- Number/date display only via next-intl global formats from `src/shared/config/i18n/formats.ts`.
- Network only via `src/shared/api/http`; paths only from `API_ROUTES` (`/api/v1/*`).
- Locales `en-GB` (default), `en-US`, `de-DE`, `ru-RU`; `localePrefix: 'as-needed'`; `en-GB` and `en-US` share `en.json`.
- Timeouts: JSON 8000 ms; stream first event 10000 ms; stream idle gap 15000 ms; no total stream cap.
- Status only for markets at `latestPeriod` with `range = '1m'`; otherwise `null`.
- Before each commit: `pnpm format && pnpm lint && pnpm typecheck && pnpm test` green.
- Conventional Commits; end each message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Unknown locale in the URL** (`/xx/dashboard`, `/de/dashboard`) → localised 404, never a crash or a silent `en-GB` render. Test in Task 7.
2. **SSE chunks split anywhere** (mid-JSON, mid multi-byte character, `\r\n` split across chunks, several events in one chunk) → events arrive whole and in order. Test in Task 3.
3. **Server accepts the request but never answers / stalls mid-stream** → `TimeoutError` after the configured time, not a hang; caller abort → `AbortedError`, not `TimeoutError`. Test in Task 3.
4. **Payload that does not match the schema** (API or `data.json` drift) → `ParseError` with issues, never `undefined` reaching components. Test in Tasks 3 and 4.
5. **Going offline and back repeatedly** → guard appears and disappears each time; children stay mounted (state preserved). Test in Task 9.
