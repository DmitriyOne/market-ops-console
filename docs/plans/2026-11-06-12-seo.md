# 0.13.0 Page metadata, icons, preview image, robots, 404 and 500

**Goal:** every page has a correct title and description in its language, the
app has a favicon and a link preview image, `robots.txt` keeps crawlers out,
the 404 and 500 pages get a real design in every language and theme, and no
visible text is left outside the dictionaries. The deploy moves to 0.14.0.

## Owner decisions (2026-11-06)

1. **Version 0.13.0**, from `develop` after 0.12.0 was merged.
2. **The site stays closed to search engines** (the 2026-11-03 decision
   stands): `robots.txt` disallows everything, the `noindex, nofollow` meta
   stays. **No sitemap**: a sitemap for pages crawlers may not visit says the
   opposite of `robots.txt`.
3. **Deploy in 0.14.0** (later moved to 0.15.0: 0.14.0 became Sentry), with the E2E run on Vercel previews (backlog). The
   absolute address that the preview image needs comes from
   `NEXT_PUBLIC_SITE_URL`, else Vercel's `VERCEL_PROJECT_PRODUCTION_URL`,
   else `http://localhost:3000`.
4. **404 and 500: design A** (canvas "Market Ops 404 & 500"): logo and app
   name in the corner, a large mono code, title, text, buttons, centred, no
   app header. 404 shows the address that was not found; 500 shows the error
   ID (`digest`) when there is one. **On a phone the button sits under the
   text, not pinned to the bottom** (owner).
5. **No visible text outside the dictionaries, enforced by lint**: audit,
   move what is found to en/de/ru, and widen the rule (below).
6. **No experimental Next.js flags in production** (owner): so no
   `global-not-found` (behind `experimental.globalNotFound`). A path the
   proxy skips (`/x.txt`, `/api/unknown`) keeps Next's own 404, in English.
   The rule goes into `CLAUDE.md` and ADR 0018.

## My calls (say if any is wrong)

- **Title:** `{page} · {appName}`, the pattern itself a message
  (`common.titleTemplate`), so the separator is translatable. Dashboard:
  "Dashboard"; 404: "Page not found"; 500: "Something went wrong".
- **Description:** the existing `common.description` per locale; the same
  text in `og:description`.
- **Favicon:** `app/icon.svg`, the 0.12.0 `Logo` mark; it follows the
  browser's light or dark scheme (`prefers-color-scheme` inside the SVG).
  `app/apple-icon.png` 180 × 180 and `app/favicon.ico` (16 + 32 px) rendered
  once from that SVG by a script in `scripts/` (`rsvg-convert` + `magick`),
  both committed, so the build needs no tool.
- **Preview image (og:image):** one design for the whole site, 1200 × 630:
  logo, app name, description; **one per language** (text from the
  dictionaries), `app/[locale]/opengraph-image.tsx` with `next/og`, built
  statically (review: Next draws it on the first request, then caches it). Every page under a locale inherits it. Fonts are committed
  files (SIL OFL), no network at build; Russian needs a font with Cyrillic
  (Space Grotesk has none: Inter fills those glyphs, checked in the build). `og:type website`, `og:site_name`, `og:locale` (`en_GB`, `de_DE`,
  …), `twitter:card summary_large_image`.
- **No `hreflang` alternates**: they help search engines, which are kept out.
- **404 inside a locale** (`app/[locale]/not-found.tsx`, reached by
  `notFound()` and the `[...rest]` catch-all, as next-intl documents): the
  new design, in that locale.
- **500 inside a locale** (`app/[locale]/error.tsx`): the new design, with
  "Try again" and "Back to dashboard", the title through React's `<title>`.
- **500 when the root layout itself fails** (`app/global-error.tsx`): today
  English only. It takes the locale from the address (the first path segment,
  else en-GB) and imports the three dictionaries directly (no providers
  exist there), with its own styles and the stored theme.
- **One screen component** for all three: `StatusScreen` in `shared/ui`
  (code, title, text, detail, actions as children), so the pages differ only
  in their texts and buttons.
- **Lint, stricter, not relaxed** (ADR 0011 gets the change):
  - more announced attributes: `aria-description`, `aria-roledescription`,
    `aria-valuetext`, `aria-placeholder`;
  - `.ts` files in the UI layers (`src/{app,pages,widgets,features,entities}`
    and `src/shared/{ui,lib}`) checked too, for strings with a space or a
    sentence's punctuation (identifiers, keys, class names pass), so a
    hand-built separator like `' · '` or `', '` is caught (review: the rule
    trims text, so separators got their own selectors; ADR 0011 lists what
    still passes);
  - left out, written down: `shared/api` and `app/api` messages are for
    developers in API responses and logs; the UI shows translated texts by
    error code, never `error.message`.
- **What the audit found** (2026-11-06, a strict trial run of the rule):
  separators built in code in seven places (`StatusTile`, `HeatGrid`,
  `use-heat-format`, `ComparisonRadar`, `use-kpi-format`, `use-sheet-labels`,
  `reference.ts`): each becomes a message with placeholders or next-intl's
  `format.list`, so de and ru read naturally; the title separator; the
  English-only global error page. Nothing else visible.

## Risks

- Paths the proxy skips (`/x.txt`, `/api/unknown`) show Next's own English
  404 (no experimental flags, decision 6). Nobody reaches them from the UI.
- `robots.txt` stops crawling but not a link to the site from elsewhere: a
  search engine can list the bare address without content. The `noindex`
  meta cannot be read by a crawler that obeys the disallow. Accepted for an
  internal console.
- The preview image's absolute URL is `localhost` until 0.14.0 sets the
  deployed address: link previews work only after the deploy.
- The wider lint rule may flag strings that are not text (a format pattern
  with a space); each such case is fixed in code or listed in ADR 0011, the
  rule is not loosened.

## Found during the release

- **The lint plugin skips some attributes on native tags**: `i18next/no-literal-string`
  checks `aria-description` and the like only on components, trusting its own list on
  `<p>`, `<div>`. A `no-restricted-syntax` selector covers them (probed: it fires).
- **The wider rule found more than the audit**: a hand-joined name on the map
  (`use-map-format`), the Excel selection list and anomalies (`2026-03: …` → `Mar 2026: …`
  in the UI language), the copied sources of an answer (`; `). All moved to the
  dictionaries. The CSV keeps its machine format (ADR 0011 lists it).
- **axe flagged the big status code** (`text-border`, about 1.3:1) although it is
  `aria-hidden`: it uses `text-input` now, 3.3:1 in both themes, a little darker
  than the design.
- **The 404 and 500 titles are set on the client** (React `<title>`), so the server
  HTML of a 404 has the general title until hydration; the tab shows the right one.
  Accepted (closed to search engines; backlog).
- **Steiger forbids deep imports from `src/pages`**: the global error page's wiring
  (dictionaries, locale from the address, logging) lives in `app/global-error.tsx`;
  the page only draws (review: the page slice is gone, the screen is drawn in
  `app/global-error.tsx` from modules only).
- **A client-side crash has no error ID**: Next gives a `digest` for server errors
  only; the line is left out then.
- **Checked by hand** (production build on :3100): 404 in de (desktop, light) and ru
  (phone, dark), status 404, the title in the tab; 500 in de (dark) from a throwing
  page and the global 500 in ru from a crash in the layout (both temporary, not
  committed); the favicon in both schemes; the preview image in de and ru; `robots.txt`.

## Independent review (2026-11-06)

Fixed:
- **Critical: text and separators were still built in `.tsx`** (about fifteen
  places the `.ts` rule could not see: `· {current}`, `, {selected}` for screen
  readers, the threshold label, the heat map's anomaly list, the currency row,
  the collapsed assistant's name…). All moved to messages (`common.after`,
  `common.srAfter`, `common.separatorMark`, …) or `useJoinParts`; the lint now
  checks separators in templates, concatenation, JSX and announced attributes
  inside `{…}` (probed). What still passes is listed in ADR 0011.
- **`format.list` with `unit` joined Russian with spaces only**: the heat cell
  name is a message (`{value}, {note}`), the copied sources a `conjunction`
  list; tests in en, de, ru.
- **The global error page pulled in the `shared` barrels** (env, i18n): it is
  drawn in `app/global-error.tsx` from modules only; `localeFromPath` and
  `dashboardPath` are tested functions; the default locale links `/dashboard`.
- **The default locale's preview image went through a 307**: the proxy skips
  `opengraph-image`; E2E checks en-GB with no redirect.
- `shared/config` is no longer left out of the `.ts` text check (it had no
  findings); the error callee exception is limited to capitalised `…Error`.
- The status screen's logo and name are a `<header>`.

Recorded, not fixed: the empty server HTML of a 404 (not new, cause open), the
preview image is drawn on the first request, not at build (docs corrected),
two `<title>` elements, the full Inter files (backlog).
