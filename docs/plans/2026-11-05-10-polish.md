# 0.11.1 polish: shadcn values, total row, share in Excel, CI per check

**Goal:** close the small backlog items the owner picked and make CI readable.
A patch release: no new features. 0.12.0 stays for the deploy, favicon and preview.

## Owner decisions (2026-11-05)

1. **Version 0.11.1**, from `develop` after 0.11.0 was merged.
2. **CI: one job per check**, for both PR workflows, so each check has its own
   line and log in the PR. Into `release/*`: Format, Lint, Types. Into
   `develop`: Branch & version first (no install), then Format, Lint, Types,
   Unit tests, E2E in parallel. Accepted cost: ~13 billed minutes a run into
   `develop` instead of ~8, for ~4.5 minutes to wait instead of ~7.5
   (measured base: the 0.11.0 run; corrected in the review). `master`
   keeps its one version-check job. Replaces the "one job per workflow" rule.
3. **shadcn arbitrary values: replace what has a token or scale step, list the
   rest in DESIGN.md** with the reason.
4. **Excel share total: a formula that follows the filter** (owner chose it
   over a fixed number once it was clear the About sheet says totals follow
   the filter): revenue-weighted over the visible rows, blank where the UI has
   no share total.
5. The total cell's darker tone: fixed with an opaque mixed token, no question
   needed.

Not taken: a total row under each month in the heat map (recommended against:
a sum breaks the colour scale, ratios called "Total" mislead, the trend chart
already shows it).

## Tasks

1. **Tokens** in `@theme inline` (`globals.css`): `--color-secondary-hover`,
   `--color-table-footer` (`muted` 50 % over `card` in sRGB, the same tone the
   translucent footer had). Colours only (see the review below).
2. **shadcn** (`src/shared/ui`): `button`, `toggle`, `toggle-group`,
   `dropdown-menu`, `tooltip`, `table` use them or scale steps (`ring-3`,
   `min-w-24`, `rounded-xs`, `rounded-md` where `min(radius-md, 12px)` equals
   it). `ToggleGroup`: a class per `spacing` 0–4 instead of an inline `--gap`
   with a cast. Kept, with a comment: the xs/sm corner
   `rounded-[min(var(--radius-md),10px)]`, the sm text `text-[0.8rem]`, the
   tooltip arrow's `translate-y-[calc(-50%_-_2px)]`, `CardHeader`'s
   `grid-cols-[1fr_auto]` and `grid-rows-[auto_auto]`.
3. **Total row** (`MarketsTable`): the sticky cell `bg-table-footer`, the row
   without the hover tint (it is not a link).
4. **Excel** (`markets-xlsx.ts`): share total
   `IFERROR(SUMPRODUCT(SUBTOTAL(109,OFFSET(D4,ROW(D4:Dn)-ROW(D4),0)),J4:Jn)/SUBTOTAL(109,D4:Dn),"")`
   when `view.totals.sharePct` has a value. Tests: the formula; with no
   filter it gives the UI's number; blank off the latest month; in the
   IFERROR list.
5. **CI**: `.github/actions/setup` (pnpm, Node, cache, install);
   `pr-release.yml` and `pr-develop.yml` split into jobs.
6. **Docs**: DESIGN.md (§1 mixed tokens, §2 and §3 the kept sm/xs values, §6 the
   kept values, the stale `Tooltip` row), `.claude/rules/ui.md`,
   `.claude/rules/ci.md`, ADR 0007, README, CHANGELOG, backlog (three items
   closed).

## Independent review (2026-11-05)

Important, fixed:

1. **`text-compact` and `rounded-compact` broke `cn`'s merge.** `cn` is
   shadcn's package with tailwind-merge's default config (imported as-is,
   ADR 0002), so `text-compact` read as a text colour (a `sm` button lost its
   variant colour) and `rounded-compact` did not replace `rounded-lg` (`xs`
   got 14px). Latent: no `sm` button outside `outline`, no `xs` at all. The
   reviewer proposed a configured `cn` wrapper for every shadcn file; the
   owner kept ADR 0002 (no import fixes after each `shadcn add`) and chose to
   return the two values as shadcn wrote them, listed in DESIGN.md §6. Tokens
   stay for colours only (an unknown `bg-*` merges as a colour). Pinned by
   `button.test.tsx` (fails on the compact names).

Minor, fixed: CI minutes were estimated from the wrong base (the 0.11.0 run
was 7.5 min, 8 billed; now ~13 billed, ~4.5 to wait; release ~4 billed); a
share-total test for a product; the share weight note (column sum vs stored
revenue, ~1e-6 % apart); app-level arbitrary values and `(--x)` references
written into DESIGN.md §6; `persist-credentials: false` on the gate's
checkout; the `edited` run note in ADR 0007.

Not done: see the backlog ("From the 0.11.1 review").
